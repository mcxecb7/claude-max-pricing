## 100 美元的 Max 5x，实际能用多少？

这是搜这个关键词的人最想知道、官方又偏偏不给标准答案的部分。

Claude 的用量按**滚动 5 小时窗口**计算，不是每天零点清零。你在窗口内消耗的额度，会随着旧对话滑出窗口逐渐释放。官方没有公布具体条数，第三方测算给出的参考值是：在复杂编码任务、扩展思考开启的场景下，Pro 一个窗口大约能跑 40–45 条消息，Max 5x 大约 225 条，Max 20x 大约 900 条。这些是估算，实际浮动不小，但量级关系是准的。

两个会明显影响额度的因素：

1. **扩展思考是额度杀手**。一次深度推理回复消耗的 token 可能是普通回复的十倍以上。架构讨论、多文件重构、深挖 bug 这类任务会自动触发它。
2. **周限额独立于 5 小时窗口存在**。Max 有一个跨所有模型的每周用量上限，重置时间是系统分配给账户的固定时刻，和你什么时候开始订阅无关。用超了就只能等，在重置日之前想恢复额度，升级到更高档位是唯一的办法。

另外有一件事让"5 倍"变得更值：2026 年 5 月，Anthropic 把 Claude Code 的 5 小时限额在所有付费方案上翻了一倍，同时取消了 Pro 和 Max 的高峰期限流。现在的 5 倍乘在一个更大的基数上，实际容量比 Max 刚发布时大得多。

Cowork（把报告、表格、演示文稿这类多步任务交给 Claude 在后台跑）也共享同一份额度。有第三方的实测口径是：Pro 每天约 15–20 个任务批次，Max 5x 约 30 个，Max 20x 实际上等于不限。如果你上午跑了重型 Cowork 自动化，下午的 Claude Code 余量就会被压缩——它们吃的是同一个 5 小时窗口。

## 除了用量，Max 比 Pro 多什么？

四样东西，都是官方定价页明确列出的：

- **高峰期优先访问**。Pro 用户在流量高峰可能遇到排队或限速，Max 不会。对赶时间的专业工作，这一条经常是升级的真实理由。
- **更高的单次输出上限**。长代码文件和长报告不容易被截断。
- **新模型、新功能的优先体验权**。新东西通常先给 Max 用户。
- **每月 API 额度**。Max 和 Team 订阅附带 Claude API 的月度额度，如果你同时用 API 做自动化，这是顺手的福利。

反过来看，有些曾经的卖点已经下放了：Claude Code 和 Cowork 在 2025 年年中就开放给了 Pro。所以今天 Max 与 Pro 的差距，纯粹是容量和优先级，没有功能门禁。换句话说，如果你从没撞过 Pro 的限额，升 Max 不会解锁任何你现在用不了的东西。

## 谁该升 Max 5x，谁需要 Max 20x？

判断方法不玄学：数一数 Pro 的限额每周打断你几次真实工作。

**继续用 Pro**，如果：
- 一周被限额打断不到两次
- 用量是脉冲式的，忙一天歇两天
- 主要是对话和写作，很少跑长时间编码会话

**升 Max 5x**，如果：
- 每周的开发时段都在撞限额
- 经常在大型代码库里跑长会话
- 需要连续几小时不被打断的文档处理或研究

**上 Max 20x**，如果：
- Claude Code 是你每天 8 小时以上的主力开发环境
- Max 5x 在高强度周也嫌紧
- 同时跑 Code 和 Cowork 的并行任务
- 给客户交付的活儿，延误不可接受

成本上有笔账值得算：Max 5x 价格是 Pro 的 5 倍、额度也是 5 倍，**单条消息成本和 Pro 打平**；Max 20x 价格是 10 倍、额度是 20 倍，**单条成本直接砍半**。用量真能吃满的话，20x 反而是单位成本最低的档位。

再举个时间账：假设你的时间值每小时 150 美元，Pro 每周让你干等限额重置 30 分钟，一个月折损 300 美元，比升 5x 多花的 80 美元高得多。前提当然是你真的每周都被打断——一周撞不到两次限额，这笔账不成立，待在 Pro 更划算。

多篇第三方评测的结论比较一致：Max 5x 能覆盖绝大多数重度用户，20x 是留给把 Claude 当主力工作环境的人的。

## 几个高频问题

**Max 有年付或学生优惠吗？**
没有。Max 只提供月付，官方也没有任何可申请的长期折扣，只有不定期出现的限时活动，通常通过官方渠道公告。

**5 小时窗口和周限额是什么关系？**
两层限制并存。5 小时窗口管单次会话强度，周限额管一周总消耗，后者在账户固定的时刻重置。另外官方保留按周、按月或按模型调整额度的权利，用于保障整体服务fairness——额度规则以当期页面为准。

**用量超了会怎样？**
不会被踢下线，等下一个 5 小时窗口开始就能继续，有些情况下还能以降速方式接着用。官方文档还提到限额重置（limit reset）机制，可以把会话或周限额恢复到满额。Max 额度大，撞顶概率本身比 Pro 低很多。

**Max 5x 和 20x 功能有区别吗？**
没有。官方功能对照表里两档完全一致，差的就是额度和高峰期优先级。选哪档只看你要多少量。

**手机 App 里订阅价格一样吗？**
官方标注的 $100/$200 是网页端订阅价，移动端可能因应用商店平台而不同。想按标准价买，走网页端。
